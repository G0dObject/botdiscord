# Guildforge

Discord-бот экономики с уровнями, XP, магазином предметов, инвентарём и браузерной админ-панелью.

## Возможности

- `/balance` — баланс, уровень и текущий прогресс XP.
- `/daily` — ежедневная награда, зависящая от уровня.
- `/shop` — список активных предметов и остатки.
- `/buy item_id:...` — покупка предмета с выдачей XP.
- `/inventory` — инвентарь пользователя.
- `/capitalization` — общая капитализация сервера: монеты на балансах плюс стоимость предметов.
- `/roulette bet:...` — рулетка со ставками на любое число от 0 до 36.
- Точное число выплачивается `36x`.
- Числа разбиты на три страницы кнопок; после результата можно сразу сделать следующую ставку с той же суммой.
- История последних 10 результатов отображается сразу в сообщении после `/roulette`, до выбора ставки.
- +5 ✦ и +10 XP за сообщение, не чаще одного раза в минуту.
- +10 ✦ и +20 XP за нахождение в голосовом канале, не чаще одного раза в 5 минут.
- Админка: статистика, топ участников, создание предметов.
- Админка позволяет выдать пользователю монеты или предмет по Discord ID.
- SQLite-база создаётся в `data/guildforge.db` автоматически.

## Запуск

1. Установить Node.js 18+.
2. Выполнить `npm install`.
3. Скопировать `.env.example` в `.env` и заполнить значения:
   - `DISCORD_TOKEN` — токен Discord-приложения.
   - `CLIENT_ID` — Application ID.
   - `GUILD_ID` — ID сервера для быстрой регистрации slash-команд.
   - `ADMIN_PASSWORD` — пароль веб-панели.
   - `JWT_SECRET` — длинная случайная строка.
4. В Discord Developer Portal включить бот и пригласить его со scopes `bot` и `applications.commands`.
5. Для отслеживания сообщений и voice бот должен иметь права `View Channels`, `Send Messages`, `Read Message History` и `Connect`.
6. Запустить `npm start`.
7. Открыть `http://localhost:3000`.

Для разработки доступен `npm run dev`.
