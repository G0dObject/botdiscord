# Guildforge

Discord-бот экономики с уровнями, XP, магазином предметов, инвентарём и браузерной админ-панелью.

## Возможности

- `/balance` — баланс, уровень и текущий прогресс XP.
- `/daily` — ежедневная награда, зависящая от уровня.
- `/shop` — список активных предметов и остатки.
- `/buy item_id:...` — покупка предмета с выдачей XP.
- `/inventory` — инвентарь пользователя.
- `/capitalization` — общая капитализация сервера: монеты на балансах плюс стоимость предметов.
- `/profile [user]` — профиль, стрик daily, игровая статистика и достижения.
- `/leaderboard [type]` — рейтинг по балансу, уровню или числу игр.
- `/transfer user:... amount:...` — передача монет участнику.
- `/weekly` — еженедельная награда.
- `/promo code:...` — активация промокода; создание кодов доступно из API админки.
- `/roulette bet:...` — рулетка со ставками на одно или несколько чисел от 0 до 36.
- Каждому выбранному числу назначается указанная ставка; точное число выплачивается `36x`.
- Числа разбиты на три страницы кнопок. Кнопки ставок на красное и чёрное отсутствуют.
- Сумму ставки можно изменить кнопкой прямо в сообщении рулетки.
- Игры `/coin`, `/dice`, `/slots` и `/roulette` используют кнопки, повтор игры и изменение ставки; результаты учитываются в профиле и рейтинге.
- `/achievements [user]` показывает все достижения и даты разблокировки, а `/menu` открывает навигацию по играм, инвентарю, магазину, продаже и достижениям.
- У предметов есть редкость (`common`, `uncommon`, `rare`, `epic`, `legendary`). Кейсы - обычные предметы типа `case`; открой свой через `/open-case item_id:...`.
- `/sell` продаёт предмет боту за 50% цены; аукцион доступен через `/auction-create`, `/auction-list` и `/auction-buy`.
- `/reputation` раз в сутки выдаёт другому участнику 25 ✦.
- Достижения выдаются за первую игру и покупку, ставку от 1 000 ✦, daily-стрик в 7 дней и пятый уровень.
- История последних 10 результатов отображается сразу в сообщении после `/roulette`, до выбора ставки.
- +5 ✦ и +10 XP за сообщение, не чаще одного раза в минуту.
- +10 ✦ и +20 XP за нахождение в голосовом канале, не чаще одного раза в 5 минут.
- Админка: статистика, топ участников, создание предметов.
- Админка позволяет выдать пользователю монеты или предмет по Discord ID.
- Админские изменения баланса, предметов, промокодов, покупок и аукционов записываются в `audit_log`.
- MongoDB подключается автоматически через переменную окружения `MONGODB_URI`.

## Запуск

1. Установить Node.js 18+.
2. Выполнить `npm install`.
3. Скопировать `.env.example` в `.env` и заполнить значения:
   - `DISCORD_TOKEN` — токен Discord-приложения.
   - `CLIENT_ID` — Application ID.
   - `GUILD_ID` — ID сервера для быстрой регистрации slash-команд.
   - `ADMIN_PASSWORD` — пароль веб-панели.
   - `JWT_SECRET` — длинная случайная строка.
4. В Discord Developer Portal включить бот и пригласить его со scopes `bot` и `applications.commands`.
5. Для отслеживания сообщений и voice бот должен иметь права `View Channels`, `Send Messages`, `Read Message History` и `Connect`.
6. Запустить `npm start`.
7. Открыть `http://localhost:3000`.

Для разработки доступен `npm run dev`.

## Railway

- Railway должен использовать Node.js 22 (это закреплено в `.nvmrc` и `package.json`).
- Добавь в Variables `MONGODB_URI`, `DISCORD_TOKEN`, `CLIENT_ID`, `GUILD_ID`, `ADMIN_PASSWORD` и `JWT_SECRET`.
- В MongoDB Atlas разреши подключение Railway через `Network Access` (`0.0.0.0/0` для временной настройки).
