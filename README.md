# Guildforge Arcade

Discord Activity с общей экономикой, аркадными играми и админ-панелью.

## Возможности

- Activity открывается на `/` и авторизует игрока через Discord Embedded App SDK.
- Все ставки используют единый баланс пользователя.
- Монетка, кости и слоты имеют собственные анимации и учитывают игровые результаты.
- «21» запускает карточную игру против дилера, который добирает до 17.
- Crush: ставка списывается в начале, игрок забирает выплату по текущему множителю до крушения ракеты.
- Общая рулетка принимает по одной ставке от каждого игрока в 12-секундный раунд.
- В рулетке можно поставить на число (`36x`), красное или чёрное (`2x`) либо зеро (`14x`).
- Админ-панель доступна по `/admin/`: статистика, игроки, предметы, выдача монет и предметов.
- Достижения и игровая статистика записываются в MongoDB.

## Запуск

1. Установить Node.js 22.
2. Выполнить `npm install`.
3. Скопировать `.env.example` в `.env` и заполнить значения:
   - `CLIENT_ID` - Application ID Discord-приложения.
   - `DISCORD_CLIENT_SECRET` - Client Secret из OAuth2.
   - `ADMIN_PASSWORD` - пароль админ-панели.
   - `JWT_SECRET` - длинная случайная строка.
   - `MONGODB_URI` - строка подключения MongoDB.
4. В Discord Developer Portal добавь URL Mapping с префиксом `/` и публичным HTTPS-доменом приложения без пути `/activity/`.
5. Запустить `npm start`.
6. Открыть админ-панель: `http://localhost:3000/admin/`.

Discord bot token, `GUILD_ID`, slash-команды и права gateway больше не используются.

## Railway

- Railway должен использовать Node.js 22 (это закреплено в `.nvmrc` и `package.json`).
- Добавь в Variables `MONGODB_URI`, `CLIENT_ID`, `DISCORD_CLIENT_SECRET`, `ADMIN_PASSWORD` и `JWT_SECRET`.
- В MongoDB Atlas разреши подключение Railway через Network Access.
